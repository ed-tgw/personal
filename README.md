# Personal Blog

This is a personal blog website built with [Next.js](https://nextjs.org), bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the blog by modifying files in the `app/` directory. The page auto-updates as you edit the file.

This project uses [Tailwind CSS](https://tailwindcss.com) for styling and [TypeScript](https://www.typescriptlang.org) for type safety.

## Features

- Responsive design with Tailwind CSS
- TypeScript support
- ESLint for code quality
- App Router for routing
